# King Wijaya Elektronik

Static website for King Wijaya Elektronik.

## Files to Upload

Upload the contents of this folder to GitHub:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`
- `package.json`
- `serve.mjs`
- `.gitignore`
- `.nojekyll`
- `README.md`

Do not upload local system files such as `.DS_Store`.

## Local Preview

```bash
npm run dev
```

Then open the local URL shown in Terminal, usually:

```text
http://127.0.0.1:4177/
```

## Deployment

This is a static website, so it can be deployed to Vercel, Netlify, or GitHub Pages.

Recommended flow:

1. Create a GitHub repository.
2. Upload or push this folder's contents.
3. Connect the GitHub repository to Vercel or Netlify.
4. Connect the client's custom domain from the hosting dashboard.
5. Update the DNS records from the domain provider.

## Notes

The contact form opens WhatsApp with a prepared message. It does not use a backend server or paid WhatsApp API.
